## ローカルで確認する
Ruby 3.0以上とBundlerを用意したあと、次のスクリプトを実行してください。macOSではHomebrew版Rubyを自動で優先し、依存関係は初回実行時に自動でインストールされます。

```sh
# _site/へビルド
./local-build.sh

# 自動更新付きのローカルサーバーを起動
./local-build.sh serve
```

サーバー起動後は <http://127.0.0.1:4000/Drowse-Lab/> を開いてください。
